# Hero 广告图（4 张）

单页 HTML，按当前官网文案设计，直接在浏览器打开后截图即可替换。

## 画板尺寸

每张画板为 **660 × 1440**（与 App Store 6.9" 截图 1320×2868 同比例）。

## 截图方法

- Chrome 打开对应 HTML，F12 → 设备模拟（Cmd+Shift+M），分辨率设为 660×1440、DPR=2，
  再用「捕获屏幕截图」导出，即得 **1320×2868**（App Store 要求尺寸）。
- 或直接 Cmd+Shift+4 框选画板区域截图（画板外为灰色背景，容易对齐）。
- 站内预览替换（`public/preview/Screenshot-0X.png`，470×1024）时缩放即可，比例一致。
